# 圣犬帕拉 · 微光远征

一款受《Paladog / 圣犬帕拉》启发的原创像素单机游戏：带领动物军团，在横向战场中出兵、施法、保护英雄，体验据点战役与逐波生存。当前交付是电脑浏览器版，能够离线运行；尚未制作 Android APK。

角色像素绘制、界面、关卡与合成音乐均在本项目中实现，没有使用从原作提取的图片、音乐或代码。项目标题用于说明玩法灵感，与原作权利方无关联。

## 开始游戏

**Windows：双击 `启动游戏.cmd`，或直接用浏览器打开 `index.html`。** 推荐使用现代版本的 Microsoft Edge、Chrome 或 Firefox。运行游戏不需要安装 Node.js、不需要联网，也没有运行时第三方依赖。

游戏声音需要首次点击后才能播放，这是浏览器的正常行为。进度自动保存在当前浏览器的本地存储中。浏览器的隐私模式、清理站点数据或更换打开方式可能导致存档不可用，请阅读[完整说明](docs/GAME_GUIDE.md)。

开发时，也可以安装 Node.js 22 或更新版本后在项目目录运行：

```sh
npm start
```

打开 <http://127.0.0.1:4173>。开发服务器仅监听本机。端口可通过环境变量 `PORT` 调整。无需执行 `npm install`。

## 基本操作

| 操作 | 键盘 / 鼠标 |
| --- | --- |
| 英雄移动 | A / D 或 ← / → |
| 召唤八种伙伴 | 1—8，或点击对应卡片 |
| 施放三种魔法 | J / K / L，或点击对应技能 |
| 暂停 / 继续 | 空格或 Esc |
| 切换 1× / 2× 战斗速度 | F，或点击战斗上方的速度按钮 |
| 查看图鉴、选择装备、升级和关卡 | 点击界面按钮 |

游戏也提供触控左右移动和出兵、技能按钮，方便测试移动设备交互。电脑浏览器是本版本的主要目标平台。

## 游戏内容

- 两种独立玩法：6 章 24 关的战役，以及从营地直接进入的无尽生存。生存模式逐波增强敌军，每三波选择一次随机祝福、每五波迎战首领，并单独记录最佳成绩。
- 8 种伙伴，除剑士、游侠、重卫和法师外，还有范围投手、反伤守卫、治疗医师与冲锋野猪。
- 12 类敌人，包括飞行幽影、远程射手、快攻猎犬、重甲守卫、支援祭司和死亡爆炸的裂火虫。
- 兵种与怪物图鉴，展示基础属性、解锁关卡和战术提示。
- 帕拉可购买并切换 4 根原创权杖与 4 枚戒指；每个槽位只能装备一件，不同组合强化雷击、冰霜、治疗、资源或生存。
- 敌方据点首次降至半血会召来一队守军，首领关仍须先解除据点护盾。
- 英雄移动与自动攻击、支援光环、食物出兵、三种魔法和敌方据点。
- 营地升级、本地自动保存战役进度与生存纪录，以及会随营地、战斗、生存和首领场景变化的原创合成配乐。

2.4 版本增加战前敌军预览与最佳用时、波次倒计时、双倍战斗速度和伤害/治疗飘字，并强化首领生命与寒霜状态的提示。无尽生存会轮换不同敌军编队，第二波起会根据英雄位置调整敌军进场距离，减少等待。速度同时影响战场所有角色、资源与冷却；通关纪录始终使用游戏内时间。窄屏小地图和飘字会适应战场的实际可见区域。

旧版 12 关存档可继续使用，通关第 12 关后会开放第 13 关。

玩法、存档与常见问题详见 [游戏说明文档](docs/GAME_GUIDE.md)。

## 项目结构

```text
index.html              游戏入口，可直接打开
styles.css              桌面与触控布局、界面样式
js/engine.js            战斗规则、关卡与兵种配置
js/renderer.js          Canvas 像素绘制
js/app.js               页面交互、输入与游戏状态衔接
js/storage.js           本地存档读取、校验与保存
js/audio.js             Web Audio 合成音乐与音效
server.cjs              可选的零依赖本地开发服务器
启动游戏.cmd             Windows 一键打开入口
tests/                  Node.js 自动化逻辑测试
docs/GAME_GUIDE.md       游戏说明、开发说明与 Android 迁移规划
```

运行逻辑测试：

```sh
npm test
```

## 关于 Android

本版本采用 HTML、CSS、JavaScript 与 Canvas，资源在本地生成，不依赖后台服务。未来可以评估通过 Capacitor 或 Android WebView 打包；仍需补充真实设备性能测试、横屏适配、生命周期与系统返回键处理、应用图标及签名发布流程。当前没有 APK，也不声明已经完成手机端兼容验证。
