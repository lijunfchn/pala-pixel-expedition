# 原创像素美术说明

战场与营地的像素画面全部由 `js/renderer.js` 中的 Canvas 代码和像素矩阵实时绘制，不请求外部图片，不包含原版游戏图片、图标或音频。页面布局和控制面板由 `index.html` 与 `styles.css` 绘制。

- 画布：560 × 240 的内部画面，按屏幕尺寸及设备像素比例放大；关闭平滑缩放，保留像素边缘。
- 场景：翡翠森林、失落遗迹、永夜森林、霜石山脉、赤焰荒原和破晓天际。远山、针叶林、近树和地面采用不同镜头移动速度；冰晶、熔岩、祭坛石柱及天气粒子区分新区域。
- 友军：白犬骑士与八种动物伙伴。新版增加松鼠的蓬尾和松果、刺猬的荆刺盾、猫头鹰的翅膀与治疗杖、野猪的长枪与獠牙；主角也改为更高、更细的像素矩阵。
- 敌军：十二类敌人，包括射手、幽影、猎犬、重甲守卫、祭司和裂火虫。敌塔使用灰紫石材、魔晶及守护护盾。
- 动画：行走起伏、振翅、近战挥动、远程投射物、冲锋轨迹、爆炸、光环、治疗、冰霜、雷击、命中粒子及营火。

`Pala.drawIcon(canvas, kind)` 会用同一套人物矩阵生成角色 UI 图标，法术图标则以同一色板程序绘制，保持界面与战场的风格一致。新增兵种时，在 `sprites` 中加入像素矩阵，并在 `gear` 中补充装备轮廓；新增场景时，在 `palettes` 中定义色板。

装备图标由 `Pala.drawEquipmentIcon(canvas, id)` 绘制；帕拉手中的权杖宝石与戒指颜色也会随当前装备变化。据点半血召援后会出现红色裂纹与闪光，提示玩家进入最后攻坚阶段。

美术为本项目原创程序化素材。项目的名称、题材和规则受经典横版召唤策略游戏启发；没有复制商业原作的美术资产。
